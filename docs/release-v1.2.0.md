# 留白 WhiteSpace v1.2.0

首页从三幕固定舞台改为自然连续滚动；山雾由内联 SVG 和 CSS 绘制，移除241张动画帧、原封面和视频处理链路，避免滚动时等待图片下载／解码。

## 已通过

- 类型、Lint、生产构建；281项单元测试。已删除仅服务旧帧库的9项测试。
- 首轮33项真实Chrome浏览器测试通过；新增隐藏状态／监听清理用例后，最终首页与导航19项通过。CI将执行最终34项完整浏览器测试。
- 390／768／1280／1440px首页，无横向溢出；导航另含320px检查。示例入口、菜单焦点、页面往返、输入保留、邀请码取消及会话失效恢复已回归。
- 生产版冷缓存940ms可读、热缓存876ms、1.6Mbps／150ms／4倍CPU限速1852ms。滚动RAF间隔P95≤16.8ms，滚动长任务、布局偏移、动画媒体请求与静止应用RAF均为0。
- 实际浏览器预览确认首屏与介绍区连续衔接、开始规划可进入现有工作台；生产性能测试未捕获页面异常。

## 边界与待验证

- 本次没有调整百炼、API、邀请码或业务规则；未重复付费模型调用。上版真实百炼验证不可当作本版新测试结果。
- 设备和网络结果来自自动化浏览器样本；未全面实测实体手机、Safari、所有地区。RAF调度间隔不是GPU呈现帧率保证。
- 首轮开发测试记录过一次Next.js路由初始化异常；最终19项定向开发测试与两轮生产性能验证均未复现。
- 网页仍需要下载正常HTML、CSS和JavaScript，背景不需要额外下载媒体。接受简化山雾不再复刻原视频的取舍。
- 线上部署、CI和公网保护验证结果在发布后补录。

验收方式及固定门槛见[首页性能](home-performance.md)。现有邀请保护和限流说明见[公共Demo](demo.md)。
