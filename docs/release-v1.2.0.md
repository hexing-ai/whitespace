# 留白 WhiteSpace v1.2.0

首页从固定三幕切换改为自然连续滚动，山雾由内联SVG和两层CSS渐变绘制。移除241张动画帧、原封面和视频处理链路，正文不再等待背景下载或解码。首屏保留品牌与小标语，介绍和行动入口由内容决定高度，顶部可随时开始规划或定位段落。

## 实际边界

网页仍需加载正常HTML、CSS和JavaScript；此次移除的是额外动画媒体加载。简化山雾不再逐帧复刻原视频。只在桌面精细指针、足够宽度且未要求减少动态效果时播放；其他情况使用同一静态构图。

RAF间隔是主线程调度代理指标，不保证GPU实际帧率；冷缓存慢滚出现过一次66.7ms间隔。Safari、实体手机及所有地区未全面验证，本机预览工具访问Vercel曾超时。初轮开发测试出现一次Next.js路由初始化日志；最终定向测试、最终CI与生产性能验证均未复现。

百炼、邀请码与业务规则没有变化，本次未重复付费模型调用。以往真实百炼成绩不当作本版重新执行结果。原有邀请保护与限流边界见[公共Demo说明](demo.md)。
