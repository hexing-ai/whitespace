# 原山景与自然滚动

v1.3.0根据用户明确反馈恢复原参考视频的视觉及“随滚动推进”的背景。正文继续自然滚动；不再使用v1.2.0的SVG几何山形，也不恢复旧固定三幕舞台。

## 实现边界

- 三个正文段落按正常文档流上下移动，首屏显示品牌；后两段为原来的大字理念与开始行动，含简短说明。后两段没有视口高度约束，不吸附、不锁轮、不切换正文透明度。
- 固定在视口的装饰Canvas只处理背景；滚动进度映射到原视频的0至10秒帧时间轴。向下前进、向上倒放，停止滚动后完成附近预取即停止RAF。
- 恢复同一份241张1280×720WebP帧（总4.13MB）和原封面。仍需要下载媒体，不能称为零加载；正文不等待媒体就绪，访客不下载或转换MP4。
- 同一原片生成175342字节的预览图，包含121个320×180画面。预览就绪后，滚动时直接从中取对应画面；停下120ms后补清晰帧。预览之外最多12个位图，合计13；最多4项并发，快速滚动中止远离目标的请求。预览加载失败时仍可按需读取原大图，没有额外指数平滑造成跟随延迟。
- 正文与导航明暗颜色以实际显示帧为准，背景未追到位时不先切换白字。深色场景添加轻微暗层以保护可读性。
- 隐藏／离屏暂停，退出取消请求并关闭位图。触屏、小屏、减少动态效果、省流量或能力不足显示原山景封面，正文继续自然滚动；失败不重置阅读位置。

## 验收

```bash
npm run build
npm run start
node scripts/check-home-performance.mjs
```

浏览器测试覆盖真实帧时间轴、前进／后退、自然布局、四档尺寸、静态模式、媒体阻塞与失败、快速请求调度、图片资源清理和工作台往返。生产性能报告在Git忽略的`test-results/home-scenery/`，线上可通过Online Demo / home运行。

记录正文RAF调度间隔与背景实际绘制次数／间隔，两者分开，不能用正文滚动流畅声称背景一定逐帧流畅。固定性能门槛：普通10Mbps／20ms、受限1.6Mbps／150ms／4倍CPU；正文RAF间隔P95分别≤50／100ms，滚动长任务≤200ms，CLS<0.1，首背景帧4／10秒内可见；普通／受限跳转端点2.5／6秒内到位。预览与目标资源完成后静止应用RAF为0，无视频或Worker请求。预览模式缓存最多13（缺预览的基础加载器上限24）。任何弱网下的背景等待都不能冻结正文或入口。

性能及截图需针对恢复的原素材重新采集，v1.2.0的零媒体请求成绩不适用于本版。实际成绩与限制见发布记录。


预览在滚动过程中会比720p大图柔和，这是同一原画面的清晰度分级，不替换内容。极弱网络仍需等待封面／预览资源；用户可立即滚动和进入规划。原片及派生预览的许可边界见第三方声明。
