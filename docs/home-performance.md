# 三幕首页还原

v1.3.1按用户要求恢复自然滚动改版前的首页（历史提交48617c1）。首页组件、样式、三幕控制器和帧加载器恢复该版本；邀请码、后端、工作台保留当前版本。

桌面使用500svh滚动距离驱动固定100svh舞台，依次显示品牌、产品理念、海面行动区。章节导航定位到0、45%、90%，非当前正文隐藏并退出键盘交互。原241张720p图片帧按需加载，不运行视频转换Worker。恢复旧版平滑参数与24个位图上限，不继续使用v1.3.0的低分辨率预览。

触屏、小屏、减少动态效果和能力不足使用原版三段静态阅读；初始等待保留封面，入口始终可用，下载过慢或失败时降级。隐藏暂停、退出释放资源。

```bash
npm run build
npm run start
node scripts/check-home-performance.mjs
```

报告位于被忽略的test-results/home-progressive。普通10Mbps／20ms检查原帧加载量、首帧、实际背景绘制、空转与位图上限；受限1.6Mbps／150ms／4倍CPU检查旧版静态降级和入口可用。弱网降级通过不代表弱网动态效果流畅，也不能套用v1.3.0预览版的指标。

本次优先恢复原视觉与三幕交互，不能保证消除旧版所有加载或卡顿。具体通过项与待验证项目见[还原记录](release-v1.3.1.md)。
