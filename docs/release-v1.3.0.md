# 留白 WhiteSpace v1.3.0

恢复原参考视频的雪山、云雾与海面画面，同时让正文按正常文档流连续滚动。背景随下滚前进、随上滚后退；不恢复固定三幕舞台。品牌、LOGO和原大字排版保留。

## 体验调整

- 移除v1.2.0的几何山形，恢复原素材与明暗配色。
- 三个内容段落连续上下移动，后两段不强制满屏；背景独立绘制，不锁定正文，不重置滚动位置。
- 175KB原视频预览覆盖整个过程，滚动先跟随，停下120ms后补清晰大图。避免快滚仍排队等已离开的画面。
- 导航常驻，滚动后加底色避免文字重叠；仍能随时开始规划和返回产品首页。
- 隐藏暂停、退出清理；触屏、小屏、减少动态效果或不可用时显示原山景封面。工作台不加载首页效果。

## 验证与限制

- 291项单元测试，含原媒体哈希、预览覆盖、快速请求优先级、清晰度补充和资源释放。
- 最终独立CI通过：291项单元测试、37项真实浏览器测试，类型检查、Lint与生产构建全部通过。线上首页与邀请码保护验收均通过。
- 预览版生产冷／热／弱网测试通过，正文滚动RAF间隔P95≤16.8ms。弱网首背景帧约2.64秒、完整小预览约3.43秒就绪，之后首尾位置响应31–32ms；冷／热首帧934／880ms。静止RAF均为0、CLS为0、无滚动长任务。背景位置绘制间隔P95为99–117ms（本测试滚轮每65–80ms发送一次，包含浏览器调用耗时），与正文RAF指标分别记录，不宣称背景60fps。单次样本不保证所有网络和设备。
- 预览是原素材的较低分辨率版本，滚动时比720p清晰帧柔和；停止后补清晰。网页仍需下载素材，不宣称零加载。
- 真实百炼与邀请码业务代码未改，本次未重复付费模型调用。Safari、实体手机和所有地区未全面验证。
- 初轮开发测试中途更新代码曾使1280px样式短暂卸载；停止热更新后完整36项回归通过。最终生产检查又发现冷启动网络估算变化唤醒一次RAF，已改为只有省流量偏好改变时重配，新增定向回归通过。生产和最终CI单独验收。
